Ders Tercihleri

Supabase Kurulumu

Supabase panelinde aşağıdaki SQL kodunu çalıştırın. Sonra Project URL ve anon/public key bilgisini Yönetici paneline girin.

SQL Tablo ve Yetki Kodu

create table if not exists public.teacher_preferences ( id bigint generated by default as identity primary key, created_at timestamptz default now(), teacher_id text, teacher_name text, course_key text, course_name text, course_type text, grade text, hour numeric, preference_value integer, preference_label text, submission_time text, row_no integer, submission_id text, is_active boolean default true ); alter table public.teacher_preferences add column if not exists submission_id text; alter table public.teacher_preferences add column if not exists is_active boolean default true; alter table public.teacher_preferences enable row level security; drop policy if exists "public_insert_teacher_preferences" on public.teacher_preferences; create policy "public_insert_teacher_preferences" on public.teacher_preferences for insert to anon with check (true); drop policy if exists "public_select_teacher_preferences" on public.teacher_preferences; create policy "public_select_teacher_preferences" on public.teacher_preferences for select to anon using (true); drop policy if exists "public_update_teacher_preferences" on public.teacher_preferences; create policy "public_update_teacher_preferences" on public.teacher_preferences for update to anon using (true) with check (true);
Supabase → SQL Editor → New query → kodu yapıştır → Run. Daha sonra Project Settings → API bölümünden Project URL ve anon/public key bilgilerini alın.
