Ders Tercihleri

Dersler sade görünüm için Alan Dersleri ve MESEM Dersleri olarak gruplandı. Önceden gönderdiğiniz tercihler varsa Supabase’den otomatik getirilir ve değiştirilebilir. Tercih gönderimi için zorunlu kural: Alan derslerinde 1 Çok isterim, 2 İsterim, 2 Olabilir, 1 Mecbur kalırsam; MESEM derslerinde 1 Çok isterim seçilmelidir.
Alan Çok isterim0/1
Alan İsterim0/2
Alan Olabilir0/2
Alan Mecbur0/1
MESEM Çok isterim0/1

Yönetici Paneli

Öğretmenleri ekleyin. Her öğretmene sistem otomatik 4 haneli şifre verir. Başka tarayıcılarda da öğretmenlerin görünmesi için işlem bitince Paylaşılacak Form HTML'yi İndir düğmesine basıp çıkan dosyayı paylaşın/yükleyin.

Admin Şifre Yönetimi

Supabase ayarları girilirse tercihler doğrudan buluta kaydedilir. Google Apps Script gerekmez.

Supabase Kurulumu

Supabase panelinde aşağıdaki SQL kodunu çalıştırın. Sonra Project URL ve anon/public key bilgisini Yönetici paneline girin.

SQL Tablo ve Yetki Kodu

Supabase → SQL Editor → New query → kodu yapıştır → Run. Daha sonra Project Settings → API bölümünden Project URL ve anon/public key bilgilerini alın.
